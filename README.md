- **Tech:** Next.js, Supabase, Drizzle ORM, Stripe Connect, Expo, React Native

### Nova · Senior Full-Stack Developer
Multi-tenant CRM that US call centers use to sell warranty contracts. Ship features and fixes across the Next.js front end and Django REST API, including payment syncing and recurring billing flows.
- **Tech:** Next.js, TypeScript, Django REST, Azure DevOps

### [WorkWhale](https://www.workwhale.ph) · Software Engineer
Remote job marketplace built from scratch. 10,000+ job pages generated from Postgres, each server-rendered with its own metadata, canonical, and JobPosting JSON-LD. Subscription tiers through Stripe and AI resume parsing and job matching.

### [Jooma](https://www.jooma.ai) · Software Engineer
AI teaching platform with 35 tools that generate UK curriculum-aligned lessons and worksheets. Full UI implemented pixel-accurate from Figma, with real-time streaming and PDF and DOCX export.
- **Tech:** Next.js, TypeScript, Claude API, Tiptap

### [Light Logic](https://www.lightlogic.com.sg) · Software Engineer
Company website for a Singapore lighting firm, plus LumaLens, an AI lighting design platform using Claude vision with Zod-validated output.
- **Tech:** Next.js, Supabase, Node.js, Claude API
